# Ressources récoltables (format : docs/DATA_FORMAT.md).
#
# Un bloc par type : [resource identifiant], puis ses lignes « clé = valeur ».
#   name      : nom affiché (français)
#   shape     : forme provisoire tant qu'il n'y a pas de modèle : tree, rock, bush ou vein
#   item      : objet gagné à chaque coup, « identifiant quantité » (objet de items.txt)
#   hits      : coups avant épuisement (1 à 1000)
#   hit_ticks : ticks entre deux coups avec l'outil (20 ticks = 1 s ; à la main : 2 fois plus)
#   tool      : outil qui récolte à pleine vitesse (facultatif, une ligne par outil)
#   hand      : yes (défaut) ou no : récoltable sans outil ?
#   regrow    : ticks avant la repousse, une fois épuisée
#   abundance : poids relatif au placement dans le monde (0 : jamais placée d'office)
#
# L'ordre des blocs compte : client et serveur doivent lire le même fichier (le type circule
# sur le réseau par son rang). Valeurs provisoires, à équilibrer en jeu.
